## Sobre mim

- Formado em **Desenvolvimento de Sistemas para a Internet** e pós-graduado em **Desenvolvimento de Jogos Digitais**.
- Mais de 20 anos fazendo sites institucionais, sistemas de gestão, plataformas e jogos para a web.
- Gosto de cuidar das duas pontas: o visual e a usabilidade no front-end, e a segurança, a regra de negócio e o banco de dados no back-end.
